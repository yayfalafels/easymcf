# Easy MCF

Easy MCF helps job seekers in Singapore track MyCareersFuture roles, manage their lead pipeline, and automate application follow-up without leaving the local machine. The app is built for a local workflow: search, qualify, track, and apply from one place using the seeded database and fixture mode during development.

Current version: `0.1.0`

See the [release notes](https://github.com/yayfalafels/easymcf/blob/main/docs/releases/010/010-release.md) and the [developer guide](developer-guide/index.md) for setup and local usage.
