# Easy MCF Version 0.2.0 - Milestones

## Branch convention

Work happens on the `dev` branch and reaches `main` through a pull request from `dev`. A push to `main` publishes the documentation site. A release is the merge of `dev` into `main`, tagged with the release id.

## Feature milestones

The `seq` column determines the implementation order. Ids 01 to 06 are reserved for the release's planning milestones, following the `010` pattern.
