The CVs page stores labels for resumes already saved in your MyCareersFuture profile. Easy MCF does not upload or store the resume file. Automation uses a label to choose the matching resume on MCF.

## Add or rename a CV label

1. Open **CVs** from the Tracks page or **Manage CVs** from the Applications page.
2. Under **CV label**, enter a recognizable label that matches a resume available in your MCF profile, then select **Add label**.
3. To correct an existing label, select **Rename** beside it, edit the text, and select **Save label**.
4. Return to the page you came from with **Back to tracks** or **Back to applications**.

The labels correspond to substrings or complete matches to CV that you have uploaded into MyCareerFutures.  For example, for a CV `Edward Smith CV v14.3`, you can use the version tag substring `14.3` to uniquely match to this uploaded CV. A label that does not match an MCF resume can block a lead from the apply batch or produce `cv_not_found` during a run.

## Assign a default CV

Open **Tracks**, choose the track's **Default CV**, and save the track. Leads on that track use the default unless a specific lead has its own override. A lead without an effective CV cannot be included in the apply batch until you assign one.

To use a different resume for one lead, change the CV in that lead's row on **Applications**. That override does not change the track default.

## Remove a CV label

Select **Remove** beside the label and wait for the active label list to refresh. A label that is still referenced by tracks, leads, or application history is retired from selection rather than erasing historical records. Before removing a label, assign a replacement to any track or queued lead that still needs to use it.

## Fix a resume match

If Applications marks a lead as blocked, choose another active CV label for the row or rename the label so it matches a resume in MCF. Confirm the blocked message disappears before starting the batch. If the label is correct but MCF still cannot find the resume, sign in to MCF and verify that the resume is present there, then reconnect Easy MCF if the session is no longer valid.
